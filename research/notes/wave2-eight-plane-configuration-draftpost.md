# Draft discussion comment — `eight-plane-configuration` (#176) — exclusion results, wave 2 (2026-11-01)

**Status: no witness; rigorous lower bound deg D ≥ 7 for denominators of any Y-parity, with the shape of any denominator of degree ≤ 9 pinned down (Jacobian/tangency type with a quadratic Hessian condition).** The pure-parity degree-7 Gröbner certificate (483 quadrics in 60 variables per parity) did not complete in this round (the run was OOM-killed on a shared machine) and is resubmitted. Nothing below claims nonexistence of a certificate.

Setup: `q = 1`, `A = X0^3 Y0^3`, `F` the 236-term τ-even sextic, `J = J(F)`, `R = S/J` (Gorenstein, socle 24). Certificates come in τ-pairs and `D·τD` is again a denominator, so *some* certificate has τ-even `D`; a minimal-degree one need not, so the degree bounds below cover `D` of pure and of mixed Y-parity. "Rigorous" below means proved over `Q` (hence `C`); modular computations are made rigorous by the rank argument stated in each item.

1. **E1 kernel (rigorous).** For `d ≤ 9` and both parities, `{D ∈ S_d : A·D ∈ J} = J_d`, i.e. `Ann_R(A)_d = 0`. Computed with three primes (2147483647, 2147483629, 2147483587) and two independent code paths (nullspace of `[A·m | J_{d+6}]`; normal forms in `R_{d+6}`). Rigor: `dim_Q ker ≤ nD − rank_p[A|J] + dim_Q J_{d+6}`, and in every row `rank_p J_{d+6}` equals the exact Koszul dimension `dim_Q J_{d+6}` (parity-refined Hilbert series `(1−t^5)^3(1−st^5)^3/((1−t)^3(1−st)^3)`), so `dim_Q ker ≤ kerdim_p = dim_Q J_d`. At `d = 10` the kernel modulo `J` has exactly the forced dimension `294` (even) / `261` (odd) (= `R_10^± − R_8^∓`), i.e. multiplication by `A` is surjective `R_10 → R_16`.

2. **Jacobian-type reduction (exact).** Hence for `d ≤ 9` every certificate denominator is `D = w(F) = Σ w_i ∂_iF` for a polynomial vector field `w` with coefficients in `S_{d−5}` (`X ∩ V(D)` is the tangency locus of `w`), coprime to `F` iff `w ∉ {h·Euler}`. For such `D`, E1 has the particular solution `N₀ = A·w`, and the whole certificate problem is *equivalent* to the Koszul-reduced system: find `c_ij ∈ S_{d−4}`, `Q ∈ S_{2d−6}` with `[D·div N₀ − N₀(D)] + Σ_{i<j}[D(F_j∂_i c_ij − F_i∂_j c_ij) − c_ij(F_j D_i − F_i D_j)] = F·Q` (the Euler-multiple freedom `g·E/6` cancels identically). Reducing modulo `J` gives the necessary **Hessian condition** `A·Hess_F(w,w) ∈ J_{2d}` (for `d ≤ 7`: `Hess_F(w,w) ∈ J_{2d−6}`), which only depends on `w` modulo `{h·Euler}`.

3. **Degrees ≤ 6 are excluded (rigorous).** `d ≤ 4`: `J_d = 0`. `d = 5`: `Hess_F(w,w) ∈ J_4 = 0` forces the second directional derivative of `F` to vanish; the linearized map `Sym²(W) → S_4` has full rank 6, so `w = 0` — this covers the whole 3-dimensional families `span(F_{X_i})`, `span(F_{Y_i})`, not just the six partials. `d = 6`: `w` a linear vector field (18 parameters per parity, minus the Euler field); the quadric ideal `(NF_J Hess_F(w',w'))` has Hilbert function `[1,17,18,2,0]` (even) / `[1,18,18,2,0]` (odd) (msolve, grevlex, two primes; Singular cross-check by another agent), so `(S/I)_4 = 0` mod p, hence over `Q` (a Macaulay rank can only drop mod p), hence the only solution is `w' = 0`. For mixed-parity `w = w₊ + w₋` (35 variables, 405 quadrics) the quotient algebra is finite as well (dimension 923). **No coprime degree-6 denominator of any parity admits a certificate.** Cross-checks: the Koszul-reduced systems of 11 named `J_6` elements (`E_i(F)`, `ε_X(F)`, `X_0F_{X_0}`, `R_0(F)`, …) are inconsistent with two primes, and all six partials `∂F/∂Z_i` are inconsistent over the exact rationals (flint `fmpq`, rank 102 vs 103 — no prime involved).

4. **Degree 7.** For pure-parity `w` the Hessian condition is 483 independent quadrics in 60 variables per parity (`W'_7 = W_7/{h·E}`); the Gröbner run (degree of regularity 4, ~40+ GB) was interrupted and is resubmitted. For mixed-parity `w` it is 951 quadrics in 120 variables (degree of regularity ≥ 5), beyond direct Gröbner reach. Already excluded rigorously at `d = 7` (both parities): gradient fields `w = ∇G` (`D = ∇F·∇G`, `G` cubic; linearization rank 406 = dim Sym²), arrangement-preserving fields `Σ h_iR_i + Σ g_iE_i` (`R_i` block rotations, `E_i` block Eulers), fields supported on the `X`-components or the `Y`-components, and fields with coefficients in `C[X]` or `C[X_0,Y_0]` (msolve quotient dimensions 29, 708, 439, 203, 13).

5. **Degree 8.** The Hessian condition becomes `Hess_F(w,w) ∈ Ann_R(A)_{10}^+` (294-dimensional inside `R_{10}^+`), i.e. 468 quadrics in 156/159 variables — beyond Gröbner reach (Hilbert-series bound: degree of regularity ≥ 8). Excluded rigorously so far: all Hamiltonian fields `w = C·∇G` (`C` constant antisymmetric, `D = Σ C_ij F_iG_j`, a combination of Jacobian minors of `(F,G)`) for `G ∈ {K_i, H_i, diag_i, Q_iQ_j, Q_i²}` — linearization has full rank in every case — Hamiltonian fields for random quartics `G`, fields with coefficients in `C[X_0,Y_0]` or in `C[X_0,X_1,X_2]` (msolve quotient dimensions 28 and 4006), and all single-component fields `h·∂_{Z_i}` (`D = h·F_i`, quotient dimension 740 in all 12 cases). At `d = 7`, 140 individual fields (random, arrangement-preserving, Hamiltonian pairs and random-`C` Hamiltonian fields for ~40 cubics `G`, gradient fields) were tested with the full Koszul-reduced system: all inconsistent with the same signature (rank 996, augmented 997, 1056 unknowns). Larger `d = 8` subfamilies (arrangement-preserving with quadratic coefficients, all gradient fields `∇G`, `G ∈ S_4`) and `d = 8, 9` sampling are pending remote capacity.

6. **Sum principle bookkeeping.** For every natural low-degree factor tested — `Q_i`, `Q_i ± Q_j`, `ΣQ_i`, `X_iY_i`, `X_i² − Y_i²`, `X_0²`, `X_0X_1`, `X_0Y_1` (degree 2); `K_i`, `H_i`, `diag_i`, `Q_i²`, `Q_iQ_j` (degree 4); `Q_0Q_1Q_2`, Fermat (degree 6) — the annihilator `Ann_R(D)_6^{odd} = ker(·D : R_6^- → R_{6+deg D})` is zero (rigorous by the same rank argument as item 1, since `rank_p J_{6+deg D}` is the exact value), so `served(D) ⊆ J`; for degree ≤ 4 the full served space computed mod p is exactly `J_6^-` (dimension 18, the trivial floor). These divisors serve no nonzero class, so by the sum principle `served(D_1D_2) = served(D_1) + served(D_2) mod J` no product of them (e.g. `g_5(Q_0,Q_1,Q_2)`, `Q_0Q_1Q_2·G_4` with `G_4` from this list) can serve `A`.
