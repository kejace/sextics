# Draft discussion comment — `eight-plane-configuration` (#176) — exclusion results, wave 2 (2026-11-01)

**Status: no witness; rigorous lower bound deg D ≥ 7 (≥ 8 if the pending degree-7 Gröbner run confirms), with the shape of any low-degree denominator pinned down.** Nothing below claims nonexistence of a certificate.

Setup: `q = 1`, `A = X0^3 Y0^3`, `F` the 236-term τ-even sextic, `J = J(F)`, `R = S/J` (Gorenstein, socle 24). WLOG `D` has pure Y-parity (`D ↦ D·τD`). "Rigorous" below means proved over `Q` (hence `C`); modular computations are made rigorous by the rank argument stated in each item.

1. **E1 kernel (rigorous).** For `d ≤ 9` and both parities, `{D ∈ S_d : A·D ∈ J} = J_d`, i.e. `Ann_R(A)_d = 0`. Computed with three primes (2147483647, 2147483629, 2147483587) and two independent code paths (nullspace of `[A·m | J_{d+6}]`; normal forms in `R_{d+6}`). Rigor: `dim_Q ker ≤ nD − rank_p[A|J] + dim_Q J_{d+6}`, and in every row `rank_p J_{d+6}` equals the exact Koszul dimension `dim_Q J_{d+6}` (parity-refined Hilbert series `(1−t^5)^3(1−st^5)^3/((1−t)^3(1−st)^3)`), so `dim_Q ker ≤ kerdim_p = dim_Q J_d`. At `d = 10` the kernel modulo `J` has exactly the forced dimension `294` (even) / `261` (odd) (= `R_10^± − R_8^∓`), i.e. multiplication by `A` is surjective `R_10 → R_16`.

2. **Jacobian-type reduction (exact).** Hence for `d ≤ 9` every certificate denominator is `D = w(F) = Σ w_i ∂_iF` for a polynomial vector field `w` with coefficients in `S_{d−5}` (`X ∩ V(D)` is the tangency locus of `w`), coprime to `F` iff `w ∉ {h·Euler}`. For such `D`, E1 has the particular solution `N₀ = A·w`, and the whole certificate problem is *equivalent* to the Koszul-reduced system: find `c_ij ∈ S_{d−4}`, `Q ∈ S_{2d−6}` with `[D·div N₀ − N₀(D)] + Σ_{i<j}[D(F_j∂_i c_ij − F_i∂_j c_ij) − c_ij(F_j D_i − F_i D_j)] = F·Q` (the Euler-multiple freedom `g·E/6` cancels identically). Reducing modulo `J` gives the necessary **Hessian condition** `A·Hess_F(w,w) ∈ J_{2d}` (for `d ≤ 7`: `Hess_F(w,w) ∈ J_{2d−6}`), which only depends on `w` modulo `{h·Euler}`.

3. **Degrees ≤ 6 are excluded (rigorous).** `d ≤ 4`: `J_d = 0`. `d = 5`: `Hess_F(w,w) ∈ J_4 = 0` forces the second directional derivative of `F` to vanish; the linearized map `Sym²(W) → S_4` has full rank 6, so `w = 0` — this covers the whole 3-dimensional families `span(F_{X_i})`, `span(F_{Y_i})`, not just the six partials. `d = 6`: `w` a linear vector field (18 parameters per parity, minus the Euler field); the quadric ideal `(NF_J Hess_F(w',w'))` has Hilbert function `[1,17,18,2,0]` (even) / `[1,18,18,2,0]` (odd) (msolve, grevlex, p = 2147483587), so `(S/I)_4 = 0` mod p, hence over `Q` (a Macaulay rank can only drop mod p), hence the only solution is `w' = 0`: **no coprime degree-6 Jacobian denominator admits a certificate**, in either parity. Cross-checks: the Koszul-reduced systems of 11 named `J_6` elements (`E_i(F)`, `ε_X(F)`, `X_0F_{X_0}`, `R_0(F)`, …) are inconsistent with two primes, and all six partials `∂F/∂Z_i` are inconsistent over the exact rationals (flint `fmpq`, rank 102 vs 103 — no prime involved).
