## 0. Reading guide and rigor conventions (consolidated from the verify lenses)

* **Setting.** Certificate for `(F, q, A)`: `A D² − q D Σ N_i F_i + F (D div N − N(D)) = F^{q+1} Q`, `deg N_i = d + 6q − 5`, `deg Q = 2d − 6`, `d = deg D`, `gcd(D, F) = 1`. Variables `X0,X1,X2,Y0,Y1,Y2`; `τ: Y ↦ −Y`. At `q = 1` the class is `Res(AΩ/F²) ∈ H^{3,1}(X)`; a certificate with denominator `D` ⟺ the class is supported on `Z = X ∩ V(D)` (book ch. 3 §3.1); only the reduced support matters (prescribed-support theorem), so at `q = 1` excluding `D` excludes all `D^m`, and `served(D₁D₂) = served(D₁) + served(D₂)` for coprime factors (sum principle).
* **E1 / Jacobian filter.** `E1: Σ N_i F_i = A D` (after the Euler normalisation) ⟺ `[A]·[D] = 0` in `R = S/J(F)`. `D ∈ J(F)` always passes; the non-trivial part is `Ann([A])_d = ker([A]: R_d → R_{d+6q})` ("E1 kernel mod J"). **Rigor:** `0 mod p ⇒ 0 over ℚ` *provided* `rank_p J_{d+6q}` equals the characteristic-0 Hilbert value (checked in every lane; the Hilbert functions of all 16 Jacobian rings are the smooth values in degrees 5–9 at p = 10⁹+7 — aggregator). A positive mod-p dimension is an upper bound; exactness needs rational lifts.
* **E2 / Hessian relaxation (the wave-2 workhorse).** For `D = w(F)`, `N = A w + (H/6)E + K` (K Koszul), and reducing E2 modulo `J` gives the necessary condition `A·wᵀHess(F)w ∈ J_{2d}` (quadratic in w; for `d ≤ 7`, where `[A]` is injective on `R_{2d−6}`, equivalently `wᵀHess(F)w ∈ J_{2d−6}`). "Only the trivial solution" certified mod p (msolve `-g 1` leading ideal m-primary, or Singular dim 0, or a Macaulay matrix of full column rank) transfers to ℂ by properness/semicontinuity *when the mod-p Jacobian blocks have their Hilbert ranks*. The gauge direction `w ∈ h·Euler` (`D ∈ F·S`) must be removed first.
* **Fixed-D exclusions.** "inconsistent mod p" is rigorous over ℚ only when `rank_p(M) = rank_Q(M)` — certified by an explicit rational kernel of the right dimension (structural kernel `(G z, 0) ⊕ (gF, D div g − g·∇D)`: 129 at d = 5, 244 at d = 6, …), by an exact rank over ℤ, or by an **exact Farkas dual** `y` with `yᵀM = 0, yᵀb ≠ 0`. Tags used below: **[exact]** (ℚ/ℤ arithmetic or certified), **[mod p]** (one prime, uncertified), **[2 primes]**, **[reported]** (thread claim not replayed locally), **[screened]**.
* **Parity / symmetry caveats (verify lenses).** (i) "WLOG D has pure Y-parity" is a WLOG for *existence* (`D ↦ D·τ(D)` doubles the degree), *not* for degree-by-degree bounds: a mixed-parity `D` of degree d must be covered by running the relaxation on the full mixed w-space (E1 itself splits by parity because J is τ-graded). (ii) Likewise semi-invariance under a finite diagonal group is not WLOG at fixed degree (orbit products multiply the degree). Bounds quoted as "any parity" below have this covered.
* **Dimension-forced kernels.** Smooth sextic: Gorenstein `R` with socle degree 24, parity-split Hilbert function `R_d^+ = 1,3,12,28,66,123,218,333,483,623,762,843,885,…`, `R_d^- = 0,3,9,28,60,123,208,333,468,623,744,843,866,…`. For `q = 1`, Y-odd `A` of degree 6: `[A]: R_d^± → R_{d+6}^∓` is square at `d = 9` and has forced kernel ≥ 294 (even) / 261 (odd) at `d = 10`, ≥ 510 at 11, ≥ 677/648 at 12. "Kernel = 0 for d ≤ 9" is therefore the strongest E1 statement; E1 stops filtering at `d = 10` in every q = 1 lane.
