## 0. Reading guide

* **Setting.** Certificate for `(F, q, A)`: `A D² − q D Σ N_i F_i + F (D div N − N(D)) = F^{q+1} Q`, `deg N_i = d + 6q − 5`, `deg Q = 2d − 6`, `d = deg D`, `D` coprime to `F`. Variables `X0,X1,X2,Y0,Y1,Y2`; `τ: Y ↦ −Y`. At `q = 1` the class is `Res(AΩ/F²) ∈ H^{3,1}(X)`; a certificate with denominator `D` ⟺ the class is supported on `Z = X ∩ V(D)` (book ch. 3 §3.1); only the reduced support matters (prescribed-support theorem), so at `q = 1` excluding `D` excludes all powers `D^m` and products are governed by the sum rule `served(D₁D₂) = served(D₁) + served(D₂)` (coprime factors).
* **E1 filter.** `E1: Σ N_i F_i = A D` (mod the Koszul/Euler gauge) is necessary; it says `[A]·[D] = 0` in the Jacobian ring `R = S/J(F)`. `D ∈ J(F)` always passes E1 ("polar/tangency divisors" `D = w(F)`), so the interesting quantity is `Ann([A])_d = ker([A]: R_d → R_{d+6q})` ("E1 kernel mod J"). **Rigor:** a mod-`p` kernel dimension bounds the characteristic-0 dimension from above, so `0 mod p ⇒ 0 over ℚ` (rigorous); a positive mod-`p` value is an upper bound.
* **Fixed-D exclusions.** "inconsistent mod p" is rigorous over ℚ exactly when the mod-`p` rank of the coefficient matrix equals its ℚ-rank (true for all but finitely many `p`; certified when a report says "exact"/fmpq, or when the rank matches a characteristic-free dimension count). Entries are tagged **[exact]** (over ℚ), **[mod p]** (one prime), **[2 primes]**, **[numeric]**, **[reported]** (thread claim, not replayed locally), **[screened]** (random sampling/numerical, not an exclusion).
* **Dimension-forced kernels.** For a smooth sextic `R` is Gorenstein with socle degree 24 and parity-split Hilbert function `R_d^+ = 1,3,12,28,66,123,218,333,483,623,762,843,885,…`, `R_d^- = 0,3,9,28,60,123,208,333,468,623,744,843,866,…`. For `q = 1`, `deg A = 6`, Y-odd `A`: `[A]: R_d^± → R_{d+6}^∓` is square at `d = 9` and has forced kernel `≥ 294 (even) / ≥ 261 (odd)` at `d = 10`, `≥ 510` at `d = 11`, `≥ 677/648` at `d = 12`. So "E1 kernel = 0 for d ≤ 9" is the strongest possible E1 statement and E1 stops filtering at `d = 10` for every `q = 1` lane.
