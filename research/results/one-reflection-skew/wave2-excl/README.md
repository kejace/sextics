# wave2-excl packet: exclusion / rigor for `one-reflection-skew` (q = 1, A = X0^3 Y0^3)

Everything here is reproducible from the scripts in this directory (python3 + python-flint 0.9, msolve, Singular).
Conventions: variables X0,X1,X2,Y0,Y1,Y2; we use F7 = 7F (integer coefficients); f7 = F7 - 7 Y2^6; t = Y2.
Diagonal symmetry group (24 elements) generators g1=(3,3,3,0,0,0), g2=(0,3,0,3,0,0), g3=(4,1,4,4,1,0); the
"fine sector" of a monomial e is (e.g1, e.g2, e.g3) mod 6; rbajaj5's 2-torsion class is (e0+e1+e2, e0+e2+e3, e0+e2+e4, e5) mod 2.

## What is proved rigorously here (statements)
* RIGOR CONVENTION. "exact" = computed over Q with python-flint fmpz/fmpq (no prime). Modular steps are only used in
  one-sided ways: (i) a Macaulay/Groebner computation mod p showing (S_p/I_p)_k = 0 for the ideal generated by EXACT
  integer quadrics implies (S_Q/I_Q)_k = 0 (rank over Q >= rank mod p), hence V_C(I) = {0};  (ii) a fixed-D linear
  system that is inconsistent mod p is certified over Q by an exact rational dual vector y (y^T M = 0, y^T b = 1),
  found by Dixon lifting and verified exactly ("EXCLUDED-exact").  Single-prime inconsistency alone is recorded as
  "inconsistent-modp" (evidence only).
* Certificate normalization used: for fixed D, a certificate exists iff E1: N(F) = A D and E2: B_D(N) = F Q are
  solvable (Euler normalization); gauges valid at fixed degree: D ~ D + F L, N ~ N + Koszul syzygy.
* Relaxation used for linear families D = sum lambda_a D_a: with exact lifts N_a, E2 reads
  sum_{a<=b} lambda_a lambda_b b_ab + sum_a lambda_a B_{D_a}(K) = F Q; replacing the products lambda_a * (Koszul coeff)
  by independent unknowns gives NECESSARY quadratic conditions y^T b(lambda) = 0 for every exact y killing all
  columns B_{D_a}(K) (all characters of K) and F S.  "mod-J stage" = the same with y killing J_{2d}[psi] (Koszul
  corrections automatically vanish mod J).  Squares lambda_a^2 in the exact Q-span of the quadrics kill coordinates.

## Files
* w2x.py        library (sectors, exact E1 kernels/lifts, fixed-D exact tests, relaxations, Macaulay, msolve/Singular IO)
* w2x5.py       strict Y2-free (five-variable) reduction (lemma in the report) and its pipeline
* job_degree.py <d>            6-variable pipeline (stages A-D) for the gauge-fixed E1 kernel at degree d
* job_d7_sub.py <d> <cases>    6-variable sub-family pipeline + msolve zero-dimensionality (cases odd/even/tor:XXXX/full)
* job5_degree.py <d> <cases>   Y2-free strict pipeline + msolve (cases all/tor:XXXX)
* job_e1dims.py <d...>         exact E1-kernel dimensions per sector (receipts e1dims_d<d>.json, bases e1basis_d<d>.pkl)
* job_families.py              structured products of invariants: rigorous E1 batch + exact E2 fixed-D tests
* job_extra_dirs.py            exact fixed-D tests of every non-Jacobian kernel basis direction (5-var and 6-var)
* relax_bank.py                correction-column bank (6-var) for branch-and-relax
* *.log.jsonl                  one JSON line per experiment (local: ../wave2-excl.log.jsonl; remote-*.log.jsonl)
* d7_*.json / d7_*.pkl         degree-7 receipts (family, quadrics, survivors, leaves), d7_sector_table.json
