## Engine/tooling notes for the aggregator
* `hodge.fixed_d.FixedDSystem.solve` returns `rank` = rank of the augmented matrix and `nullity = cols - rank_aug`; for inconsistent
  systems the nullity of M is one more than reported. Any cross-lane [RANK] certification that compares an exact nullity with
  this reported value would be off by one (the wave-2 w2lib code computes rank M separately and is unaffected).
* msolve is not used by this packet; Singular 4.3.2 (`std`, `minAssGTZ`) and sympy 1.12 Groebner bases are.
* `wave2-excl/README.md` hard-codes `/tmp/hodge/...` and `/home/kejace/devel/sextics-work`; see `README-referee.md` for a
  stranger's replay recipe.
